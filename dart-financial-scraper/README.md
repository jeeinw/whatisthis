# DART 기업 재무제표 통합 수집·분석 도구

DART(전자공시시스템, https://dart.fss.or.kr) Open API로 원하는 기업의 원하는 기간 동안
**연결/별도 재무상태표·손익계산서·포괄손익계산서·현금흐름표**를 모두 긁어와 엑셀로 정리하고,
전년대비 급변동·부호반전·자본잠식·부채비율/유동비율 같은 **재무제표 특이사항을 자동 탐지**하며,
사업보고서 원문에서 **우발부채·소송·담보·특수관계자거래 등 리스크 관련 주석 키워드**를 찾아 설명을 붙이고,
**최대주주 현황/변동, 소액주주 현황, 5% 대량보유·임원 지분보고**와 **사업부문별 손익 언급(원문 발췌)**까지 한 번에 정리합니다.

## 준비물

1. Python 3.8 이상 (별도 라이브러리 설치는 필요 없습니다 — 스크립트가 처음 실행 시
   `requests`, `pandas`, `openpyxl`, `beautifulsoup4`를 자동으로 `pip install` 합니다.
   인터넷 연결만 있으면 됩니다.)
2. DART Open API 인증키 — https://opendart.fss.or.kr 에서 회원가입 후
   "인증키 신청/관리" 메뉴에서 무료로 즉시 발급받을 수 있습니다.

## 실행 방법

```bash
export DART_API_KEY=발급받은인증키
python dart_report.py --corp 삼성전자 --start-year 2021 --end-year 2023
```

또는 인증키를 옵션으로 바로 전달할 수도 있습니다.

```bash
python dart_report.py --corp 삼성전자 --start-year 2021 --end-year 2023 --api-key 발급받은인증키
```

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `--corp` | 회사명(부분일치 검색) 또는 8자리 DART corp_code |
| `--start-year`, `--end-year` | 조회할 사업연도 범위 |
| `--reprt-codes` | 콤마로 구분. `11011`=사업보고서(연간, 기본값), `11012`=반기, `11013`=1분기, `11014`=3분기 |
| `--out` | 결과 엑셀 파일 경로 (기본값: `회사명_DART분석_시작연도-종료연도.xlsx`) |
| `--skip-notes` | 사업보고서 원문 다운로드·주석/부문 스캔을 생략해 실행 속도를 높임 |

예: 최근 4개 분기(연간+분기) 흐름을 보고 싶다면

```bash
python dart_report.py --corp LG화학 --start-year 2023 --end-year 2024 --reprt-codes 11011,11012,11013,11014
```

## 결과 엑셀 구성

- `회사개요`: 업종, 대표자, 결산월, 상장일 등 기업 기본 정보
- `연결_재무상태표` / `별도_재무상태표`, `연결_손익계산서` / `별도_손익계산서`,
  `연결_포괄손익계산서` / `별도_포괄손익계산서`, `연결_현금흐름표` / `별도_현금흐름표`,
  (자본변동표가 있으면 `연결_자본변동표` 등도 포함): 계정과목 × 연도(보고서) 피벗 테이블
- `핵심_재무비율`: 부채비율, 유동비율, 영업이익률, 순이익률 등을 연결/별도·연도별로 계산
- `특이사항_요약`: 전년대비 ±30% 이상 변동, 흑자/적자 전환, 자본잠식, 부채비율 200% 초과,
  유동비율 100% 미만 등 자동 탐지 결과
- `최대주주현황`, `최대주주변동현황`, `소액주주현황`, `대량보유상황보고(5%rule)`,
  `임원ㆍ주요주주소유보고`: 보유지분 및 지분변동 관련 원자료
- `주석_키워드스캔`: 사업보고서 원문에서 우발부채/소송/담보/특수관계자거래/손상차손/
  계속기업 불확실성 등 리스크 키워드가 등장한 문단을 발췌하고 의미를 설명
- `부문별_원문발췌`: "부문"이라는 단어와 매출/영업손익이 함께 언급된 문단 발췌
  (사업부별 매출·손익 비중 파악에 참고)

콘솔에도 핵심 특이사항, 최대주주 현황, 주석 키워드 스캔 결과 요약이 한글로 출력됩니다.

## 알아두어야 할 한계

- **주석/부문별 정보는 100% 구조화되어 제공되지 않습니다.** DART Open API는 재무제표 본문
  계정과목만 표준화된 형태(JSON)로 제공하고, 주석 텍스트와 세그먼트(사업부문)별 손익은
  사업보고서 원문 문서 안에만 존재합니다. 이 스크립트는 원문을 내려받아 키워드로
  검색·발췌하는 방식으로 이를 보완하지만, **정확한 숫자나 문맥은 반드시 `원문링크`
  (`https://dart.fss.or.kr/dsaf001/main.do?rcpNo=...`)에서 직접 확인**해야 합니다.
- 비상장사이거나 특정 연도에 사업보고서를 제출하지 않은 회사는 일부 데이터가 비어 있을 수
  있습니다.
- DART Open API는 일일 호출 한도가 있습니다(계정당 제공되는 한도 내). 여러 회사를 한 번에
  대량으로 조회하는 용도로 만들어진 도구가 아니며, 개별 기업 분석 목적의 적당한 호출량을
  가정합니다.
- 지분공시 API(`hyslrSttus`, `hyslrChgSttus`, `majorstock`, `elestock` 등)의 필드명은
  DART 정책에 따라 바뀔 수 있어, 콘솔 요약과 엑셀 시트에는 원자료를 최대한 그대로 담았습니다.
- 자동 탐지된 "특이사항"은 회계·법률적 판단이 아니라 단순 임계치/키워드 기반 스크리닝입니다.
  투자 판단 등에 사용할 경우 반드시 원문과 전문가 검토를 거치세요.

## 폴더 구성

```
dart-financial-scraper/
├── dart_report.py     # 메인 스크립트 (그대로 실행하면 됨)
├── requirements.txt    # 참고용 의존성 목록 (스크립트가 자동 설치하므로 필수는 아님)
└── README.md
```

실행 중 생성되는 `.dart_cache/`(기업 고유번호 캐시, 7일간 재사용)와 결과 `*.xlsx` 파일은
git에 커밋하지 않도록 `.gitignore`에 등록되어 있습니다.
