# 유튜브 쇼츠 생성

유튜브 URL을 받으면 쇼츠 3개를 만든다.

## 순서

1. **영상 다운로드** — `yt-dlp`로 원본 영상을 `output/` 폴더에 다운로드한다.
2. **자막 생성** — `whisper`로 음성을 텍스트로 추출한다.
3. **하이라이트 선정** — video-analyzer 서브에이전트에게 자막을 넘기고, 쇼츠로 만들기 좋은 구간 3개를 받는다 (`video_analyzer.md` 참고).
4. **세로 영상 클립 추출** — `ffmpeg`로 선택된 각 구간을 1080x1920 세로 비율로 잘라낸다.
5. **자막 합성** — 잘라낸 클립에 자막을 입힌다.
   - 제목: 상단, 노란색, 100pt, 굵게
   - 자막: 하단, 흰색, 74pt
6. 완성된 쇼츠 3개를 `shorts_final/` 폴더에 저장한다.

## 조건

- 각 클립 길이: 30~60초
- 클립 3개, 서로 내용이 겹치지 않게 선택
- 결과물은 `shorts_final/`에 저장

## 사용 도구

- `yt-dlp` — 영상 다운로드
- `whisper` — 자막(STT) 추출
- `ffmpeg` — 세로 클립 추출, 자막 합성
